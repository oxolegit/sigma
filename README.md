# Σ Sigma

Библиотека интерактивных курсов по техническим дисциплинам — для подготовки к контрольным и экзаменам в магистратуре НИЯУ МИФИ.

Каждый курс — уроки по одному предмету, собранные по учебнику и конспектам лекций:

- **«Что спросят»** — что нужно уметь вывести или объяснить;
- **теория** с формулами в TeX;
- **лаборатории** — графики на canvas и 3D-сцены на three.js с ползунками и строкой численных результатов;
- **пошаговые выводы**, где шаги открываются по одному;
- **проверка** — вопросы с вариантами ответа и объяснением;
- у курса — **пробная контрольная** и **шпаргалка формул** для печати.

Интерфейс на русском, работает на ноутбуке и телефоне, есть светлая и тёмная тема.

> **Статус:** готов первый курс — «Теория переноса нейтронов» (Крючков, Юрова · МИФИ, 2007): 10 уроков с 25 лабораториями (2D и 3D), пробная контрольная (26 вопросов, 10 задач) и шпаргалка формул. Остальные курсы в каталоге пока помечены как примеры.

## Стек

| | |

## Быстрый старт

Нужен Node.js 22+. E2E-тесты локально запускаются в установленном Microsoft Edge.

```sh
npm install
npm run dev        # http://localhost:4321, витрина компонентов — /dev/components/
npm run build      # astro check + сборка в dist/
npm run preview    # просмотр собранного сайта
npm test           # юнит-тесты (Vitest)
npm run test:e2e   # смоук-тесты в браузере (Playwright): 1280px светлая и 390px тёмная тема
```

## Как написать урок

Оглавление курса — в `src/content/courses/<курс>.yaml`: главы и уроки с номером, названием и параграфом учебника. Там перечислены и запланированные уроки: в оглавлении они видны, но не ссылки.

Урок — файл `src/content/lessons/<курс>/<номер>-<slug>.mdx`. Название и параграф берутся из оглавления по номеру `n`; сборка падает, если такого номера в оглавлении нет. Во frontmatter — то, что относится к самому уроку, дальше — Markdown с формулами `$…$` и `$$…$$` и компоненты:

```mdx
---
n: 4
minutes: 25
lead: Короткий вывод, на котором держится весь курс.
ask:                           # блок «Что спросят»
  - Вывести $\lambda = 1/\Sigma_t$
formulas:                      # попадут в шпаргалку курса
  - { title: Средняя длина пробега, tex: '\lambda = 1/\Sigma_t' }
---
import { Quiz, Steps } from '@components/index';
import Check from '@components/Check.astro';
import BeamAttenuation from '@labs/tpn/BeamAttenuation';

## Закон ослабления узкого пучка

$$I(x) = I_0\, e^{-\Sigma_t x}$$

<BeamAttenuation client:visible />

<Check title="Вопросы к уроку">
  <Quiz client:visible n="1" question="…" options={[{ text: '…', correct: true }, { text: '…' }]} explain="…" />
</Check>
```

Шаблон сам ставит метку «Урок 4 · §1.6 · Глава 1», заголовок, строку «≈ 25 минут · 3 лаборатории · 4 вопроса в конце» (лаборатории и вопросы считаются по исходнику), «Что спросят», оглавление и низ урока со ссылкой на следующий написанный урок.

Тонкости:

- TeX во frontmatter — в одинарных кавычках, тогда обратные слэши не нужно экранировать.
- Текстовые пропсы компонентов (вопрос, варианты ответа, объяснение, шаги вывода, пункты «Что спросят», подписи) понимают строчные формулы `$…$`: в острова Astro можно передать только строки, не JSX.
- В MDX строковые атрибуты (`question="… $\Sigma_t$ …"`) берут TeX как есть, а внутри JS-выражений (`steps={[{ tex: '…' }]}`) обратный слэш удваивается: `'\\Sigma_t'`.
- Интерактивным компонентам в MDX нужна директива `client:visible` — без неё они рендерятся статично.
- В файлах `.astro` TeX в атрибуте передавайте через `String.raw`: ``<TeX tex={String.raw`\lambda = 1/\Sigma_t`} />``. Обычная строка `tex="\frac…"` теряет обратные слэши.
- Кириллица в индексах формул — в `\text{…}`: `E_{\text{св}}`, а не `E_{св}`. Тест контента проверяет это и отсутствие табуляций (след потерянной обратной косой: `\t` в `\text`).
- Если в лаборатории цвет что-то означает, у неё должна быть легенда (`legend` у `LabFrame`), построенная из той же таблицы, по которой красится рисунок. Подписи к рисункам цвета не называют.

## Шпаргалка

Шпаргалка курса (`/<курс>/sheet/`) собирается из формул: у написанного урока — из `formulas` в его frontmatter, у запланированного — из `formulas` у этого урока в оглавлении курса. Когда урок появляется, формулы переезжают в его файл; если они остались в обоих местах, сборка падает. Печатается на А4 в две колонки, всегда в светлой теме.

## Пробная контрольная

Контрольная — `src/content/exams/<курс>.mdx`: вопросы — `ExamQuiz` (засчитываются в общий счёт вверху страницы), задачи — `Steps` с условием в `lead` и `initial={0}`, тогда решение открывается кнопкой «Показать решение». В тексте пропсов `**…**` — жирный, удобно для «**Ответ.**».

```mdx
---
title: Теория переноса нейтронов
scope: Глава 1 и §2.1–2.5
lead: 26 вопросов и 10 задач.
---
import ExamQuiz from '@components/live/ExamQuiz';
import { Steps } from '@components/index';

## Часть А. Вопросы

<ExamQuiz client:visible n="А1" question="…" options={[{ text: '…', correct: true }, { text: '…' }]} explain="…" />

## Часть Б. Задачи

<Steps client:visible initial={0} title="Б1. …" lead="Условие" steps={[{ note: '…', tex: '…' }, { note: '**Ответ.** …' }]} />
```

## Курсы-заглушки

Курс с `example: true` в YAML виден в каталоге с меткой «пример», но без страниц и ссылок. Число лабораторий у него задаётся полем `labs`; у настоящего курса оно считается по написанным урокам.

## Прогресс

Без регистрации. Пройденные уроки хранятся в `localStorage` браузера (`sigma:<курс>:<урок>`), последний открытый урок — в `sigma:last` (для «Продолжить»). Чтобы перенести прогресс на другое устройство, на странице курса есть кнопка «Ссылка на мой прогресс»: она копирует ссылку вида `…/#p=<курс>.<маска>`, при открытии которой прогресс объединяется с локальным.

## Дизайн

- **Учебник, а не приложение.** Колонка текста ~68 знаков, серифный шрифт для теории, формулы TeX, линии вместо теней.
- **Рисунок — это прибор.** Лаборатория: сцена, под ней строка чисел с единицами, ниже ручки.
- **Цвет.** Бумага, чернила и мандариновый акцент; фиолетовый — для того, на что надо обратить внимание. Цвета только через CSS-переменные из `src/styles/tokens.css`, тема переключается атрибутом `data-theme` на `<html>`.
- **Шрифты.** Только IBM Plex Sans и Source Serif 4, без моноширинных; числа — с табличными цифрами.
- **Доступность.** Цели касания от 44px, видимый фокус, состояния не только цветом, `prefers-reduced-motion`.
