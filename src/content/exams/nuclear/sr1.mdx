### Справочные данные на контрольной

<div class="sg-sr-sheet">

Формула Вайцзеккера — единственная формула, которую дадут:

$$
W(A, Z) = \alpha A - \beta A^{2/3} - \gamma\frac{Z(Z - 1)}{A^{1/3}} - \delta\frac{(A - 2Z)^2}{A} + \zeta A^{-3/4},
$$

$\alpha = 15.6$, $\beta = 17.2$, $\gamma = 0.72$, $\delta = 23.6$ МэВ; $\zeta = +34$ МэВ для чётно-чётных, 0 для нечётных, $-34$ МэВ для нечётно-нечётных ядер. Ещё дадут числа, нужные в задачах: массы атомов, $g$-факторы, плотности и т. п. В вариантах ниже они вписаны прямо в условие.

</div>

### Выучить наизусть

<div class="sg-sr-sheet">

**Константы.** $\hbar c \approx 200$ МэВ·фм (точно 197.3); $\hbar = 6.58\cdot10^{-22}$ МэВ·с; $1\ \text{а.е.м.} = 931.5$ МэВ; $m_pc^2 = 938.3$, $m_nc^2 = 939.6$, $m_ec^2 = 0.511$ МэВ; $e^2/4\pi\varepsilon_0 = 1.44$ МэВ·фм; $1\ \text{эВ} = 1.6\cdot10^{-19}$ Дж; $r_0 \approx 1.4$ фм; $1\ \text{б} = 100$ фм².

**Кинематика.** $E = \gamma mc^2 = T + mc^2$, $E^2 = (pc)^2 + (mc^2)^2$, $pc = \sqrt{T(T + 2mc^2)}$, $\beta = pc/E$, $\bar\lambda = \hbar c/pc$, $\lambda = 2\pi\bar\lambda$. Распад покоящейся частицы: $E_1 = (M^2 + m_1^2 - m_2^2)c^2/2M$. Порог: $T_{\text{пор}} = [(\sum m_f)^2 - (m_1 + m_2)^2]c^2/2m_2$.

**Свойства ядер.** $W = [Z M(^1\text{H}) + N m_n - M]c^2$, $\varepsilon = W/A$; $\varepsilon_n$, $\varepsilon_p$, $\varepsilon_\alpha$ — масса «остаток + частица» минус масса ядра. $R = r_0A^{1/3}$, $S = 4\pi R^2$, $V = \tfrac43\pi R^3$.

**Капельная модель.** Смысл пяти слагаемых; $Z_{\text{опт}} = A/(0.015A^{2/3} + 1.973)$ — выводится из $\partial M/\partial Z = 0$; энергия деления $Q = \sum W_{\text{оск}} - W$; кулоновская энергия шара $\tfrac35 Z^2e^2/R$.

**Оболочки.** Порядок уровней: 1s1/2 | 1p3/2 1p1/2 | 1d5/2 2s1/2 1d3/2 | 1f7/2 | 2p3/2 1f5/2 2p1/2 1g9/2 | 1g7/2 2d5/2 2d3/2 3s1/2 1h11/2 | 1h9/2 2f7/2 2f5/2 3p3/2 3p1/2 1i13/2; магические 2, 8, 20, 28, 50, 82, 126. Чётно-чётное — $0^+$; нечётное — $J = j$, $P = (-1)^l$; нечётно-нечётное — $|j_p - j_n| \le J \le j_p + j_n$, $P = (-1)^{l_p + l_n}$. $\mu = gJ$, $g = g_l \pm (g_s - g_l)/(2l + 1)$; протон $g_s = 5.586$, $g_l = 1$; нейтрон $g_s = -3.826$, $g_l = 0$.

**Квадруполь и ферми-газ.** $Q_0 = \tfrac45 Z\bar R^2\beta$, $\langle Q\rangle = \frac{J(2J - 1)}{(J + 1)(2J + 3)}Q_0$; $p_Fc = \frac{\hbar c}{r_0}\left(\frac{9\pi}{8}\right)^{1/3}$, $T_F = (p_Fc)^2/2m_Nc^2$, $U = T_F + \varepsilon$, $\langle T\rangle = \tfrac35 T_F$.

**Частицы в веществе.** Резерфорд: $\operatorname{tg}(\theta/2) = d/2b$, $d = zZe^2/4\pi\varepsilon_0T$, $\frac{d\sigma}{d\Omega} = \left(\frac{zZe^2}{4\pi\varepsilon_0\,4T}\right)^2\frac{1}{\sin^4(\theta/2)}$; кулоновский барьер $B = zZe^2/4\pi\varepsilon_0R$. Ионизация: $-\frac{dE}{dx} = K\frac{z^2Z}{A\beta^2}\ln\frac{2m_ec^2\beta^2}{I}$, $K = 0.307$ МэВ·см²/моль; кривая Бете — вид графиков (задачи 4.7, 4.8). Электроны: $-dE/dx = T/l_{\text{рад}}$, $T = T_0e^{-x/l_{\text{рад}}}$, $T_{\text{крит}} \approx 800/Z$ МэВ.

</div>
