## 1. Среднее и σ дискретной величины

<div class="sg-sr-sheet">

Нормировка: $\sum P(x_i) = 1$ — из неё находят константу $C$. Дальше $\bar x = \sum x_i P(x_i)$, $\overline{x^2} = \sum x_i^2 P(x_i)$, $\sigma = \sqrt{\overline{x^2} - \bar x^2}$.

</div>

<Steps client:visible initial={0} title="Разбор: P(n) = C(n + 1), n = 0…3"
  lead="Случайная величина $n$ принимает значения 0, 1, 2, 3 с вероятностями $P(n) = C(n + 1)$. Найти $C$, $\bar n$, $\sigma$."
  steps={[
    { note: '**Нормировка.** Сумма всех вероятностей равна 1:', tex: 'C(1 + 2 + 3 + 4) = 10C = 1 \\;\\Rightarrow\\; C = 0.1' },
    { note: 'Таблица: $P(0) = 0.1$, $P(1) = 0.2$, $P(2) = 0.3$, $P(3) = 0.4$. **Среднее:**', tex: '\\bar n = 0\\cdot0.1 + 1\\cdot0.2 + 2\\cdot0.3 + 3\\cdot0.4 = 2.0' },
    { note: '**Средний квадрат:**', tex: '\\overline{n^2} = 0 + 1\\cdot0.2 + 4\\cdot0.3 + 9\\cdot0.4 = 5.0' },
    { note: '**Дисперсия и σ:** $\\sigma^2 = 5 - 4 = 1$. **Ответ.** $C = 0.1$, $\\bar n = 2$, $\\sigma = 1$.' },
  ]} />

## 2. Непрерывная величина: y(x) → f(x) → x̄, σ

<div class="sg-sr-sheet">

$C = 1\big/\!\int y\,dx$, $f = C\,y$. Затем $\bar x = \int x f\,dx$, $\overline{x^2} = \int x^2 f\,dx$, $\sigma = \sqrt{\overline{x^2} - \bar x^2}$. Полезно: $\int_0^\infty x^n e^{-x}dx = n!$.

</div>

<Steps client:visible initial={0} title="Разбор: y = x(2 − x) на [0; 2]"
  lead="Дана ненормированная функция $y(x) = x(2 - x)$ на отрезке $0 \le x \le 2$ (вне его ноль). Найти плотность $f(x)$, $\bar x$ и $\sigma$."
  steps={[
    { note: '**Нормировка.**', tex: '\\int_0^2 (2x - x^2)\\,dx = \\left[x^2 - \\frac{x^3}{3}\\right]_0^2 = \\frac43 \\;\\Rightarrow\\; f(x) = \\frac34\\,x(2 - x)' },
    { note: '**Среднее.** Функция симметрична относительно $x = 1$, значит $\\bar x = 1$. Проверка:', tex: '\\bar x = \\frac34\\int_0^2 (2x^2 - x^3)\\,dx = \\frac34\\left(\\frac{16}{3} - 4\\right) = 1' },
    { note: '**Средний квадрат.**', tex: '\\overline{x^2} = \\frac34\\int_0^2 (2x^3 - x^4)\\,dx = \\frac34\\left(8 - \\frac{32}{5}\\right) = \\frac65' },
    { note: '**Дисперсия:** $\\sigma^2 = 6/5 - 1 = 1/5$. **Ответ.** $f = \\frac34 x(2 - x)$, $\\bar x = 1$, $\\sigma = 1/\\sqrt5 \\approx 0.45$.' },
  ]} />

<SrTask client:visible n="2.1"
  q="$y(x) = e^{-x/3}$, $x \ge 0$. Найти константу $C$, $\bar x$, $\sigma$."
  answers={[{ label: '$C$', value: 0.33333 }, { label: '$\\bar x$', value: 3 }, { label: '$\\sigma$', value: 3 }]}
  hint="Замена $t = x/3$ сводит всё к $\int_0^\infty t^n e^{-t}dt = n!$."
  answer="$f = \tfrac13 e^{-x/3}$, $\bar x = 3$, $\sigma = 3$." />

<SrTask client:visible n="2.2"
  q="$y(x) = x$ на $[0; 2]$. Найти $C$, $\bar x$, $\sigma$."
  answers={[{ label: '$C$', value: 0.5 }, { label: '$\\bar x$', value: 1.33333 }, { label: '$\\sigma$', value: 0.4714 }]}
  answer="$f = x/2$, $\bar x = 4/3$, $\sigma^2 = 2 - 16/9 = 2/9$, $\sigma \approx 0.47$." />

<SrTask client:visible n="2.3"
  q="$y(x) = x^2e^{-x}$, $x \ge 0$. Найти $C$, $\bar x$, $\sigma$."
  answers={[{ label: '$C$', value: 0.5 }, { label: '$\\bar x$', value: 3 }, { label: '$\\sigma$', value: 1.7321 }]}
  hint="$\int x^2e^{-x} = 2! = 2$, $\int x^3e^{-x} = 3! = 6$, $\int x^4 e^{-x} = 4! = 24$."
  answer="$f = \tfrac12 x^2e^{-x}$, $\bar x = 3$, $\overline{x^2} = 12$, $\sigma = \sqrt3 \approx 1.73$." />

## 3. FWHM

<div class="sg-sr-sheet">

Найти максимум $f_{\max}$, решить $f(x) = f_{\max}/2$, ширина — разность корней. У гауссианы $e^{-(x-\mu)^2/2\sigma^2}$ $\text{FWHM} = 2\sqrt{2\ln2}\,\sigma \approx 2.355\,\sigma$.

</div>

<Steps client:visible initial={0} title="Разбор: f(x) = e^(−(x − 5)²/8)"
  lead="Найти FWHM функции $f(x) = e^{-(x-5)^2/8}$."
  steps={[
    { note: '**Максимум.** Показатель не больше нуля и равен нулю при $x = 5$: $x_{\\max} = 5$, $f_{\\max} = 1$.' },
    { note: '**Половина высоты:**', tex: 'e^{-(x-5)^2/8} = \\frac12 \\;\\Rightarrow\\; (x-5)^2 = 8\\ln2 \\approx 5.545 \\;\\Rightarrow\\; x - 5 = \\pm2.355' },
    { note: '**Ширина:** $x_1 \\approx 2.645$, $x_2 \\approx 7.355$, $\\text{FWHM} = 2\\sqrt{8\\ln2} \\approx 4.71$.' },
    { note: '**Проверка.** Это гауссиана с $2\\sigma^2 = 8$, $\\sigma = 2$: $2.355\\cdot2 = 4.71$ — совпадает.' },
  ]} />

<SrTask client:visible n="3.1"
  q="$f(x) = \dfrac{1}{1 + (x-2)^2/9}$. Найти FWHM."
  answers={[{ label: 'FWHM', value: 6 }]}
  hint="Максимум 1 при $x = 2$. Половина: $(x-2)^2/9 = 1$."
  answer="$x = 2 \pm 3$, $\text{FWHM} = 6$." />

<SrTask client:visible n="3.2"
  q="$f(x) = e^{-|x|/2}$. Найти FWHM."

<SrTask client:visible n="3.3"

## 4. Геометрическая вероятность

<div class="sg-sr-sheet">

Точка равномерна в области $\Omega$: $P(A) = S_A/S_\Omega$. На оси времени «площадь» — длина, на квадрате двух моментов — площадь.

</div>

<Steps client:visible initial={0} title="Разбор: детектор с мёртвой зоной"
  lead="Частицы равномерно падают на квадратный детектор 10 × 10 см. В центре — нечувствительный круг радиусом 2 см. а) Какова вероятность, что частица будет зарегистрирована? б) Что попадёт ближе 1 см к краю?"
  steps={[
    { note: 'а) Вся область — квадрат, $S_\\Omega = 100$ см². Мёртвая зона $S_{\\text{кр}} = \\pi\\cdot2^2 \\approx 12.57$ см². Зарегистрирована, если не попала в круг:', tex: 'P = \\frac{100 - 4\\pi}{100} \\approx 0.874' },
    { note: 'б) Точки дальше 1 см от всех краёв образуют квадрат 8 × 8. Нужная область — рамка между квадратами:', tex: 'P = \\frac{100 - 64}{100} = 0.36' },
    { note: '**Ответ.** а) ≈ 0.87; б) 0.36.' },
  ]} />

<SrTask client:visible n="4.1"
  q="Две частицы приходят в случайные моменты внутри окна $T = 1$ мкс. Схема совпадений срабатывает, если интервал между ними меньше $\tau = 50$ нс. Найти вероятность срабатывания."

## 5. Комбинации событий

<div class="sg-sr-sheet">

Независимые — умножаем: $P(AB) = P(A)P(B)$. «Хотя бы один» $= 1 - P(\text{ни одного})$. «Ровно один» — сумма несовместных вариантов. Случайные совпадения: $\nu_{\text{сл}} = 2\tau\nu_1\nu_2$.

</div>

<Steps client:visible initial={0} title="Разбор: телескоп из двух детекторов"
  lead="Телескоп из двух независимых детекторов: эффективность первого $P_0 = 0.9$, второго $P_1 = 0.8$. Найти вероятность, что частицу зарегистрируют а) оба; б) хотя бы один; в) ровно один; г) ни один."
  steps={[
    { note: 'а) Оба: $P = 0.9\\cdot0.8 = 0.72$.' },
    { note: 'г) Ни один: $P = 0.1\\cdot0.2 = 0.02$.' },
    { note: 'б) Хотя бы один — противоположное к «ни один»: $P = 1 - 0.02 = 0.98$.' },
    { note: 'в) Ровно один: $0.9\\cdot0.2 + 0.8\\cdot0.1 = 0.26$. Проверка: $0.72 + 0.26 + 0.02 = 1$.' },
  ]} />

<SrTask client:visible n="5.1"

## 6. Бонус: мёртвое время

<div class="sg-sr-sheet">

Доля в мёртвом времени $1 - e^{-\nu\tau}$, с дополнительным каналом $1 - e^{-x}(1 + x)$, $x = \nu\tau$. Непродлевающийся тип: $n = m/(1 - m\tau)$, $\sigma_n = \sigma_m/(1 - m\tau)^2$. Подробно — [урок 6](/stats/06-deadtime/).

</div>

<Steps client:visible initial={0} title="Разбор: m = 5000 с⁻¹, t = 60 с, τ = 20 мкс"
  lead="Счётчик зарегистрировал скорость $m = 5000$ с⁻¹ за $t = 60$ с. Мёртвое время непродлевающегося типа $\tau = 20$ мкс. Найти истинную скорость $n$ и её погрешность."
  steps={[
    { note: '**Поправка:** $m\\tau = 0.1$, $n = 5000/0.9 \\approx 5556$ с⁻¹.' },
    { note: '**Погрешность измеренной скорости:** $N = mt = 3\\cdot10^5$, $\\sigma_m = \\sqrt N/t \\approx 9.1$ с⁻¹.' },
    { note: '**Перенос:** $dn/dm = 1/(1 - m\\tau)^2 = 1/0.81$, $\\sigma_n \\approx 11.3$ с⁻¹.' },
    { note: '**Ответ.** $n = 5556 \\pm 11$ с⁻¹; потери $1 - m/n = 10\\ \\%$.' },
  ]} />

<SrTask client:visible n="6.1"
  q="$\tau = 10$ мкс, $\nu = 10^4$ с⁻¹. Какая доля событий попадает в мёртвое время?"

<SrTask client:visible n="6.2"
