<div class="sg-sr-sheet">

Если события независимы и в среднем ожидается $\lambda$ событий, вероятность ровно $n$: $P_n = \frac{\lambda^n}{n!}e^{-\lambda}$, $\lambda = \nu t$, $\bar n = \lambda$, $\sigma_n = \sqrt\lambda$. Первые члены: $P_0 = e^{-\lambda}$, $P_1 = \lambda e^{-\lambda}$, $P_2 = \frac{\lambda^2}{2}e^{-\lambda}$, $P_3 = \frac{\lambda^3}{6}e^{-\lambda}$. Удобно: $P_{n+1} = P_n\cdot\frac{\lambda}{n+1}$.

</div>

## 1. Скорость счёта и её погрешность

<div class="sg-sr-sheet">

За время $t$ зарегистрировано $N$ событий: $\nu = N/t$, $\sigma_N = \sqrt N$, $\sigma_\nu = \sqrt N/t$, $\sigma_\nu/\nu = 1/\sqrt N$. С фоном ($N_b$ за $t_b$): $\nu_s = N/t - N_b/t_b$, $\sigma_{\nu_s} = \sqrt{N/t^2 + N_b/t_b^2}$ — погрешности складываются в квадратах.

</div>

## 2. Вероятность того, что N > n

<div class="sg-sr-sheet">

Хвост считать долго — переходим к противоположному событию: $P(N > n) = 1 - (P_0 + P_1 + \dots + P_n)$. **Внимание:** $P(N \ge n) = 1 - (P_0 + \dots + P_{n-1})$ — на один член меньше. «Хотя бы одно»: $P(N \ge 1) = 1 - e^{-\lambda}$.

</div>

  steps={[
    { note: '«Больше двух» — это $N = 3, 4, 5, \\ldots$, бесконечно много членов. Переходим к $N \\le 2$.' },

    { note: '$P(N \\le 2) = 0.423$, **ответ:** $P(N > 2) = 1 - 0.423 \\approx 0.58$.' },
  ]} />

## 4. Ноль событий, мёртвое время, погрешность

<div class="sg-sr-sheet">

**Ноль событий** — верхний предел: $P_0 = e^{-\lambda} = 1 - \text{CL} \Rightarrow \lambda_{\max} = -\ln(1 - \text{CL})$. CL 84 % (1σ): $\lambda < 1.84$; 90 %: $\lambda < 2.30$; 95 %: $\lambda < 3.00$.

**Мёртвое время** $\tau$ (непродлевающийся тип; $m$ — измеренная, $n$ — истинная скорость): $n = \frac{m}{1 - m\tau}$, $\sigma_n = \frac{\sigma_m}{(1 - m\tau)^2}$, $\sigma_m = \frac{\sqrt N}{t}$. Доля событий в мёртвом времени: $1 - e^{-\nu\tau} \approx \nu\tau$. С дополнительным каналом: $1 - e^{-x}(1 + x) \approx x^2/2$, $x = \nu\tau$.

</div>

## 5. Истинная скорость источника

<div class="sg-sr-sheet">

$\nu_{\text{д}}$ — скорость, которую видит детектор, $\nu_{\text{и}}$ — истинная. Событие засчитывается, если за $\tau$ до него ничего не пришло: $\nu_{\text{д}} = \nu_{\text{и}}e^{-\nu_{\text{и}}\tau}$. При $\nu\tau \ll 1$: $\nu_{\text{и}} = \frac{\nu_{\text{д}}}{1 - \nu_{\text{д}}\tau} = \frac{N}{t - N\tau}$, погрешность $\sigma = \sqrt N\,\frac{t}{(t - N\tau)^2}$.

</div>

## 6. МНК и правдоподобие

<div class="sg-sr-sheet">

Этот раздел добавлен по шестой лекции. МНК: $S = \sum\left(\frac{y_i - f(x_i)}{\sigma_i}\right)^2 \to \min$. Взвешенное среднее: $\bar a = \frac{\sum a_i/\sigma_i^2}{\sum 1/\sigma_i^2}$, $\sigma_{\bar a} = \frac{1}{\sqrt{\sum 1/\sigma_i^2}}$. Прямая: $k = \frac{\sum(x_i - \bar x)(y_i - \bar y)}{\sum(x_i - \bar x)^2}$, $b = \bar y - k\bar x$. Правдоподобие: $L = -\ln\prod P(x_i) \to \min$; для Пуассона $\hat\lambda = \bar n$, $\sigma = \sqrt{\bar n/N}$. Подробно — уроки [7](/stats/07-least-squares/) и [8](/stats/08-likelihood/).

</div>
