## Распад покоящейся частицы

Частица массы $M$ покоится и распадается на две. Импульса не было — продукты разлетаются с равными по величине импульсами $p$. Энергия сохраняется: $E_1 + E_2 = Mc^2$. Из $E_2^2 - E_1^2 = (m_2^2 - m_1^2)c^4$ сразу

$$
E_1 = \frac{M^2 + m_1^2 - m_2^2}{2M}c^2,\qquad E_2 = \frac{M^2 + m_2^2 - m_1^2}{2M}c^2,\qquad T_i = E_i - m_ic^2.
$$

Массы частиц — из таблицы П.1.5: $m_\mu c^2 = 105.66$, $m_{\pi^\pm}c^2 = 139.57$, $m_{\pi^0}c^2 = 134.98$, $m_Kc^2 = 493.68$ МэВ. Нейтрино считаем безмассовым.

## Порог реакции и система центра масс

Налетающая частица (1) бьёт в покоящуюся мишень (2). Не вся её энергия идёт на рождение новых частиц: центр масс системы движется, и его кинетическая энергия сохраняется. Работает **инвариант** — квадрат полной энергии в системе центра масс:

$$
s = (E_1 + m_2c^2)^2 - (p_1c)^2 = m_1^2c^4 + m_2^2c^4 + 2E_1m_2c^2.
$$

На пороге продукты рождаются покоящимися в с.ц.м., и $\sqrt s = \sum m_f c^2$. Отсюда

$$
T_{\text{пор}} = \frac{(\sum m_f)^2 - (m_1 + m_2)^2}{2m_2}c^2.
$$

Для ядерных реакций с малым $|Q| \ll mc^2$ это переходит в нерелятивистское $T_{\text{пор}} \approx |Q|(1 + m_1/m_2)$.

## Импульс по кривизне трека

Заряд $ze$ в магнитном поле $B$, перпендикулярном скорости, движется по окружности: $p = zeBR$. В единицах МэВ это удобно: $pc$ в эВ равно $c\cdot B\cdot R$ в СИ (при $z = 1$).

## Метод размерностей

Если ответ зависит от нескольких величин, его вид часто угадывается из единиц: подбираем показатели степеней так, чтобы размерности совпали. Безразмерный множитель метод не даёт.

<Steps
  client:visible
  title="Задачи 1.23–1.25: струна, длина пробега, капля"
  lead="Методом размерностей найти: частоту $\omega$ колебаний струны (сила натяжения $F$, масса $m$, длина $l$); длину свободного пробега $L$ частицы радиуса $r$ среди таких же с концентрацией $n$; частоту колебаний капли ($\sigma$ [Н/м], $\rho$, радиус $r$)."
  initial={0}
  steps={[
    { note: 'Струна: $\\omega = F^am^bl^c$, $[\\text{с}^{-1}] = [\\text{кг·м·с}^{-2}]^a[\\text{кг}]^b[\\text{м}]^c$. Секунды: $a = 1/2$; килограммы: $b = -1/2$; метры: $c = -1/2$.', tex: '\\omega \\sim \\sqrt{\\frac{F}{ml}}' },
    { note: 'Для однородной струны основная частота $\\omega = \\pi\\sqrt{F/(ml)}$, в ответе сборника множитель $\\sqrt2$ — метод размерностей его не различает.' },

  ]}
