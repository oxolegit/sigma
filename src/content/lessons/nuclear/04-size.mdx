## Ядерное вещество несжимаемо

Опыт показывает: радиус ядра растёт как кубический корень из числа нуклонов,

$$
R = r_0A^{1/3},\qquad r_0 \approx 1.4\ \text{фм}.
$$

Объём $\tfrac43\pi R^3 = \tfrac43\pi r_0^3A$ пропорционален $A$ — каждый нуклон занимает один и тот же объём, как молекулы в капле жидкости. Отсюда капельная модель (урок 5). Площадь поверхности $S = 4\pi R^2$ растёт как $A^{2/3}$.

## Как измерить радиус

Чтобы разглядеть объект размером $R$, нужна волна с $\lambda \lesssim R$. У α-частиц Резерфорда длина волны — несколько фемтометров, у электронов с энергией сотни МэВ — доли фемтометра.

  lead="Объекты какого размера мог исследовать Резерфорд, рассеивая α-частицы с $T = 5$ МэВ?"
  initial={0}
  steps={[
    { note: '$m_\\alpha c^2 = 3727$ МэВ $\\gg T$ — частица нерелятивистская, но формула та же:', tex: 'pc = \\sqrt{T(T + 2m_\\alpha c^2)} = \\sqrt{5\\cdot7460} = 193\\ \\text{МэВ}' },
    { tex: '\\lambda = \\frac{2\\pi\\hbar c}{pc} = \\frac{2\\pi\\cdot200}{193} = 6.5\\ \\text{фм}' },
    { note: '**Ответ.** $\\lambda \\approx 6.5$ фм — порядка размера ядра. Внутреннюю структуру ядра так не разглядеть, а вот то, что ядро маленькое и тяжёлое, — вполне.' },

## Зеркальные ядра и кулоновская энергия

В **зеркальных** ядрах протоны и нейтроны поменялись местами: $^3$H и $^3$He, $^{23}$Na и $^{23}$Mg. Ядерные силы от заряда не зависят, поэтому разница энергий связи — это разница кулоновских энергий. По ней находят радиус.

<Steps
  client:visible
  title="Задача 3.9: кулоновская энергия заряженного шара"
  lead="Получить энергию кулоновского отталкивания протонов $W(Z, R)$, считая ядро шаром с равномерно распределённым зарядом $Ze$."
  initial={0}
  steps={[
    { note: 'Наращиваем шар слоями. Шар радиуса $r$ несёт заряд $q = Ze\\,r^3/R^3$; слой $dr$ — заряд $dq = 3Ze\\,r^2dr/R^3$. Принести его из бесконечности стоит:', tex: 'dW = \\frac{q\\,dq}{4\\pi\\varepsilon_0r} = \\frac{3(Ze)^2}{4\\pi\\varepsilon_0R^6}\\,r^4\\,dr' },
    { tex: 'W = \\frac{3(Ze)^2}{4\\pi\\varepsilon_0R^6}\\int_0^Rr^4dr = \\frac35\\frac{Z^2e^2}{4\\pi\\varepsilon_0R}' },
    { note: '**Ответ.** $W = \\tfrac35 Z^2e^2/(4\\pi\\varepsilon_0R)$. В единицах ядерной физики $e^2/4\\pi\\varepsilon_0 = 1.44$ МэВ·фм. Если вычесть самодействие протонов, $Z^2$ заменяется на $Z(Z - 1)$ — так в формуле Вайцзеккера.' },
  ]}
/>
