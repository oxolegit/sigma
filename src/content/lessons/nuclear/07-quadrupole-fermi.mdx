## Квадрупольный момент — мера несферичности

Распределение заряда ядра характеризуют моментами. Дипольного у ядра нет (чётность). Следующий — **квадрупольный**:

$$
Q = \frac1e\int\rho(\vec r)\,(3z^2 - r^2)\,dV.
$$

У шара он равен нулю. Если ядро вытянуто вдоль оси $z$, то $z^2$ в среднем больше и $Q > 0$. Если сплюснуто — $Q < 0$. Единица — барн: $1\ \text{б} = 10^{-24}\ \text{см}^2 = 100\ \text{фм}^2$.

  lead="Вывести $Q = \tfrac25 Z(b^2 - a^2)$ для однородно заряженного эллипсоида вращения с полуосью $b$ вдоль оси симметрии и $a$ поперёк."
  initial={0}
  steps={[
    { note: 'Для однородного эллипсоида средние квадраты координат — как у шара, растянутого по осям: $\\langle x^2\\rangle = \\langle y^2\\rangle = a^2/5$, $\\langle z^2\\rangle = b^2/5$ (у шара радиуса $R$ $\\langle z^2\\rangle = R^2/5$).' },
    { note: 'Весь заряд $Ze$, поэтому $Q = Z\\langle 3z^2 - r^2\\rangle = Z(2\\langle z^2\\rangle - \\langle x^2\\rangle - \\langle y^2\\rangle)$:', tex: 'Q = Z\\left(\\frac{2b^2}{5} - \\frac{2a^2}{5}\\right) = \\frac25Z(b^2 - a^2)' },
    { note: 'Для малой деформации $b^2 - a^2 = (b - a)(b + a) = \\beta\\bar R\\cdot2\\bar R$:', tex: 'Q \\approx \\frac45Z\\bar R^2\\beta' },
  ]}
/>

Это **собственный** момент $Q_0$ — в системе ядра. Измеряют проекцию на ось спина, она меньше: ядро прецессирует, и вытянутость частично усредняется:

$$
\langle Q\rangle = \frac{J(2J - 1)}{(J + 1)(2J + 3)}\,Q_0.
$$

При $J = 0$ и $J = 1/2$ множитель равен нулю: такие ядра квадрупольного момента не показывают, даже если деформированы.

## Ферми-газ нуклонов

Грубая, но полезная модель: нуклоны — свободный газ фермионов в объёме ядра, яма удерживает их снаружи. В основном состоянии заняты все уровни снизу вплоть до **импульса Ферми** $p_F$, по одному нуклону на состояние (два — с учётом спина).

<Steps
  client:visible
  title="Задача 3.17: максимальный импульс"
  lead="Плотность состояний одного сорта нуклонов $dN/dp = 2\cdot4\pi p^2V/(2\pi\hbar)^3$, объём ядра $V = \tfrac43\pi r_0^3A$. Найти максимальный импульс при $N = Z = A/2$."
  initial={0}
  steps={[
    { note: 'Все состояния до $p_F$ заняты $A/2$ нуклонами:', tex: '\\frac A2 = \\int_0^{p_F}\\frac{8\\pi p^2V}{(2\\pi\\hbar)^3}dp = \\frac{8\\pi p_F^3}{3(2\\pi\\hbar)^3}\\cdot\\frac43\\pi r_0^3A = \\frac{4p_F^3r_0^3A}{9\\pi\\hbar^3}' },
    { note: '$A$ сокращается — импульс Ферми одинаков у всех ядер:', tex: 'p_F = \\frac{\\hbar}{r_0}\\left(\\frac{9\\pi}{8}\\right)^{1/3},\\qquad p_Fc = \\frac{197.3}{1.4}\\cdot1.52 = 215\\ \\text{МэВ}' },
    { note: '**Ответ.** $p_Fc \\approx 214$ МэВ. Скорость $\\beta = pc/E \\approx 0.22$ — газ почти нерелятивистский.' },
  ]}
/>

<Steps

  title="Задачи 3.18 и 3.19: энергия Ферми, глубина ямы, средняя энергия"
