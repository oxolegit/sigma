## Четыре характеристики формы

- **Мода** — наиболее вероятное значение, координата максимума: $P(n_{\text{вер}}) = P_{\max}$ или $f(x_{\text{вер}}) = f_{\max}$.
- **Квантиль** $x_\eta$ — значение, которое величина **не превышает с вероятностью** $\eta$: $F(x_\eta) = \eta$. Квантили в процентах называют процентилями, $x_{0.25}$, $x_{0.5}$, $x_{0.75}$ — первым, вторым и третьим квартилями.
- **Медиана** — квантиль $\eta = 0.5$. У выборки — такое значение, что половина элементов не меньше него, а другая половина — не больше. При чётном числе элементов берут среднее двух центральных.
- **FWHM** (Full Width at Half Maximum) — ширина на полувысоте: расстояние между точками слева и справа от максимума, где функция падает вдвое.

## Квантили и FWHM непрерывных распределений

Для непрерывной величины квантиль находят, решая $F(x_\eta) = \eta$. У распределения Коши с лекции функция распределения выражается через арктангенс, и всё считается в одну строку.

  title="Задача с лекции: f(x) = 1/(π(1 + x²))"
  lead="Найти медиану, квантили и FWHM распределения Коши. Существует ли среднее?"
  initial={0}
  steps={[
    { note: 'Нормировка уже выполнена: $\\int_{-\\infty}^{\\infty}\\frac{dx}{1+x^2} = \\pi$. Функция распределения:', tex: 'F(x) = \\frac1\\pi\\int_{-\\infty}^{x}\\frac{dt}{1+t^2} = \\frac12 + \\frac{\\operatorname{arctg} x}{\\pi}' },
    { note: 'Квантиль: $F(x_\\eta) = \\eta$. Медиана — $\\eta = 0.5$, квартили — $\\pm1$:', tex: 'x_\\eta = \\operatorname{tg}\\pi\\left(\\eta - \\tfrac12\\right),\\qquad x_{0.5} = 0,\\qquad x_{0.25} = -1,\\quad x_{0.75} = 1' },
    { note: 'FWHM: максимум $f(0) = 1/\\pi$, половина достигается при $1 + x^2 = 2$:', tex: 'x = \\pm1 \\;\\Rightarrow\\; \\text{FWHM} = 2' },
    { note: 'Среднее: $\\int x\\,f\\,dx$ на конечном симметричном отрезке равен нулю, но $\\int |x| f\\,dx \\sim \\frac1\\pi\\ln(1+x^2)$ расходится. Интеграл не сходится абсолютно — **среднего нет**, дисперсии тем более.' },
    { note: '**Вывод.** У Коши (в физике — резонансная кривая Брейта — Вигнера, форма спектральной линии) центр и ширину описывают медианой и FWHM, а не средним и $\\sigma$.' },
  ]}
/>

<QuantileLab client:visible />

Для гауссианы $e^{-(x-\mu)^2/2\sigma^2}$ полувысота достигается при $(x-\mu)^2 = 2\sigma^2\ln 2$, откуда $\text{FWHM} = 2\sqrt{2\ln2}\,\sigma \approx 2.355\,\sigma$. Если функция не решается аналитически — как $x^2e^{-x}$, — корни уравнения $f = f_{\max}/2$ ищут подбором.

## Среднее, которое не сходится
