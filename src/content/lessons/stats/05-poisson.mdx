## Пуассоновский поток

Поток событий называется пуассоновским, если выполнены три условия:

1. события **независимы** друг от друга;
2. за малый промежуток $\delta t$ может произойти **не больше одного** события;
3. вероятность события за $\delta t$ **пропорциональна** длине промежутка: $P_1 = \nu\,\delta t$.

Космические мюоны в детекторе, распады в радиоактивном препарате, фотоэлектроны при вспышке светодиода — пуассоновские потоки. Если за время $t$ в среднем ожидается $\lambda = \nu t$ событий, вероятность увидеть **ровно** $n$:

$$
P_n = \frac{\lambda^n}{n!}e^{-\lambda}.
$$

<Steps
  client:visible
  title="Вывод: откуда берётся e^(−λ)"
  initial={1}
  steps={[
    { note: 'Вероятность не получить ни одного события за $t + \\delta t$ — произведение вероятностей для независимых промежутков $(0; t)$ и $(t; t+\\delta t)$:', tex: 'P_0(t + \\delta t) = P_0(t)\\,(1 - \\nu\\,\\delta t)' },
    { note: 'Переносим, делим на $\\delta t$ и устремляем его к нулю — получаем дифференциальное уравнение с $P_0(0) = 1$:', tex: '\\frac{dP_0}{dt} = -\\nu P_0 \\;\\Rightarrow\\; P_0 = e^{-\\nu t} = e^{-\\lambda}' },
    { note: 'Так же для $n$ событий: на $(t; t+\\delta t)$ либо ничего, либо одно событие. Решение уравнений по индукции:', tex: 'P_n(t + \\delta t) = P_n(t)(1 - \\nu\\delta t) + P_{n-1}(t)\\,\\nu\\delta t \\;\\Rightarrow\\; P_n = \\frac{(\\nu t)^n}{n!}e^{-\\nu t}' },
    { note: 'Среднее и дисперсия — суммированием ряда для $e^\\lambda$:', tex: '\\bar n = \\sum n P_n = \\lambda,\\qquad \\overline{n^2} = \\lambda^2 + \\lambda,\\qquad \\sigma^2 = \\lambda' },
  ]}
/>

Главное следствие: **разброс числа отсчётов равен корню из него самого**, $\sigma = \sqrt\lambda$. Один параметр задаёт и положение, и ширину. При малых λ распределение скошено вправо (коэффициент асимметрии $\gamma = 1/\sqrt\lambda$), при больших — почти гауссово. Наиболее вероятное $n$ — целая часть λ; при целом λ одинаково вероятны $n = \lambda - 1$ и $n = \lambda$.

Удобно считать члены по цепочке: $P_0 = e^{-\lambda}$, дальше $P_{n+1} = P_n\cdot\lambda/(n+1)$.

## Больше, меньше, хотя бы одно

«Больше двух» — это $N = 3, 4, 5, \ldots$, бесконечно много членов. Считают противоположное событие — конечную сумму.

<Steps
  client:visible
  title="Задача: λ = 3, найти P(N > 2)"
  initial={0}
  steps={[
    { note: 'Переходим к противоположному событию: $P(N > 2) = 1 - P(N \\le 2) = 1 - (P_0 + P_1 + P_2)$.' },
    { note: 'Три члена, $e^{-3} \\approx 0.0498$:', tex: 'P_0 = 0.0498,\\qquad P_1 = 3e^{-3} = 0.149,\\qquad P_2 = \\tfrac92 e^{-3} = 0.224' },
    { note: '**Ответ.** $P(N > 2) = 1 - 0.423 \\approx 0.58$.' },
  ]}
/>

> **Внимание к границе.** $P(N \ge n) = 1 - (P_0 + \dots + P_{n-1})$ — на один член меньше, чем в $P(N > n)$. «Хотя бы одно» — это $P(N \ge 1) = 1 - e^{-\lambda}$.

## Скорость счёта и её погрешность

Детектор за время $t$ зарегистрировал $N$ событий. Скорость счёта $\nu = N/t$, а её погрешность берётся из пуассоновского разброса самого $N$: $\sigma_N = \sqrt N$.

<Steps
  client:visible
  title="Задача с лекции: 204 события за 10 с"
  lead="Детектор за $t = 10$ с зарегистрировал $N = 204$ события пуассоновского потока. Найти скорость счёта и её погрешность, пренебрегая погрешностью времени."
  initial={0}
  steps={[
    { note: 'Скорость: $\\nu = 204/10 = 20.4$ с⁻¹.' },
    { note: 'Число отсчётов распределено по Пуассону, его разброс:', tex: '\\sigma_N = \\sqrt{204} \\approx 14.3' },
    { note: 'Время точное — делим на него и погрешность:', tex: '\\sigma_\\nu = \\frac{\\sqrt N}{t} = 1.43\\ \\text{с}^{-1},\\qquad \\frac{\\sigma_\\nu}{\\nu} = \\frac{1}{\\sqrt N} \\approx 7\\ \\%' },
    { note: '**Ответ.** $\\nu = 20.4 \\pm 1.4$ с⁻¹.' },
  ]}
/>

Относительная погрешность зависит только от $N$: чтобы получить 1 %, нужно набрать $N = 10^4$ отсчётов, при $\nu = 50$ с⁻¹ это 200 с. Если есть фон, его измеряют отдельно ($N_b$ за $t_b$) и вычитают; погрешности при этом **складываются в квадратах**: $\sigma^2 = N/t^2 + N_b/t_b^2$.

## Отсутствие результата — тоже результат

Не зарегистрировано ни одного события. Это не значит, что $\lambda = 0$: и при $\lambda = 2$ ноль выпадает в $e^{-2} \approx 13.5\ \%$ опытов. Но слишком большие λ можно **исключить**: при них ноль был бы слишком маловероятен. Выберем уровень доверия CL и потребуем $P_0 \ge 1 - \text{CL}$:

$$
e^{-\lambda} = 1 - \text{CL} \;\Rightarrow\; \lambda_{\max} = -\ln(1 - \text{CL}).
$$

| Уровень доверия | 84 % (1σ) | 90 % | 95 % |
|---|---|---|---|
| $\lambda <$ | 1.84 | 2.30 | 3.00 |

Число 1.845 с лекции — из пособия: правая граница при $k = 0$, где хвост «$\le k$» взят равным 15.8 % — как у гауссианы за $+1\sigma$. В пособии для 95 % дано 3.68: там 5 % делят на два хвоста, $e^{-\lambda} = 0.025$.

## Малая статистика: несимметричные погрешности

При малом числе отсчётов $k$ формула $\pm\sqrt k$ врёт: распределение несимметрично, и правая погрешность больше левой. Границы находят из условий «вероятность увидеть $k$ или меньше — 15.8 %» (правая) и «$k$ или больше — 15.8 %» (левая). Например, при $k = 1$ получается $1^{+2.30}_{-0.83}$, а не $1 \pm 1$.

| $k$ | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| $\sigma_{\text{л}}$ | 0 | 0.83 | 1.29 | 1.64 | 1.92 | 2.16 |
| $\sigma_{\text{пр}}$ | 1.84 | 2.30 | 2.64 | 2.93 | 3.17 | 3.39 |
