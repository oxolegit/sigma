## Какая доля событий теряется

Событие не будет записано, если оно пришло, пока установка занята предыдущим, — за время $\tau$ после него. Для пуассоновского потока вероятность того, что за $\tau$ до события пришло хоть одно другое, — «хотя бы одно» из урока 5:

$$
P_{\text{потерь}} = \sum_{n \ge 1} P_n = 1 - P_0 = 1 - e^{-\nu\tau} \approx \nu\tau.
$$

При малых $x$ потери с одним каналом $\approx x$, а с двумя $\approx x^2/2$: второй канал выигрывает тем больше, чем меньше загрузка. В примере 3.4 пособия спектрометрический тракт с $\tau = 50$ мкс при $\nu = 2000$ с⁻¹ теряет 9.5 %, а в режиме «пинг-понг» — 0.47 %.

## Истинная скорость счёта

Обратная задача: детектор насчитал $N$ событий за $t$ и показывает $\nu_{\text{д}} = N/t$. Какова скорость источника $\nu_{\text{и}}$? Событие засчитывается, если за $\tau$ до него ничего не пришло, — вероятность этого $P_0 = e^{-\nu_{\text{и}}\tau}$:

$$
\nu_{\text{д}} = \nu_{\text{и}}\,e^{-\nu_{\text{и}}\tau}.
$$

Это трансцендентное уравнение. Его решают разложением экспоненты.

  title="Задача с лекции: 2370 нейтронов за 10 с"

  initial={0}
  steps={[
    { note: 'Детектор видит $\\nu_{\\text{д}} = 2370/10 = 237$ с⁻¹. Поправка не мала: $\\nu_{\\text{д}}\\tau = 0.1185$.' },
    { note: '**Первое приближение:** $e^{\\nu\\tau} \\approx 1 + \\nu\\tau$, тогда $\\nu_{\\text{д}}(1 + \\nu_{\\text{и}}\\tau) = \\nu_{\\text{и}}$:', tex: '\\nu_{\\text{и}} = \\frac{\\nu_{\\text{д}}}{1 - \\nu_{\\text{д}}\\tau} = \\frac{237}{0.8815} \\approx 269\\ \\text{с}^{-1}' },
    { note: '**Второе приближение:** оставим и $(\\nu\\tau)^2/2$ — получится квадратное уравнение:', tex: '\\tfrac12\\nu_{\\text{д}}\\tau^2\\nu_{\\text{и}}^2 - (1 - \\nu_{\\text{д}}\\tau)\\nu_{\\text{и}} + \\nu_{\\text{д}} = 0 \\;\\Rightarrow\\; \\nu_{\\text{и}} = 271\\ \\text{или}\\ 29\\,484\\ \\text{с}^{-1}' },
    { note: 'Физический корень — ближайший к измеренному, 271 с⁻¹. Второй соответствует режиму, где детектор почти всё время «глух», — его отбрасываем. Точное решение уравнения — 271.5 с⁻¹.' },

    { note: '**Ответ.** $\\nu_{\\text{и}} \\approx 271 \\pm 6$ с⁻¹ (первое приближение даёт 269). Без поправки было бы 237 — детектор теряет 12 % событий.' },

На лекции все варианты собраны на одном графике: исходные 237 с⁻¹ далеко внизу, а первое, второе приближения и точный корень — около 270 в пределах погрешности. В лаборатории — та же картина: кривая $\nu_{\text{д}}(\nu_{\text{и}})$, горизонталь измеренной скорости и оба корня.

## Два типа мёртвого времени

Формула $\nu_{\text{д}} = \nu_{\text{и}}e^{-\nu_{\text{и}}\tau}$ описывает **продлевающееся** мёртвое время: каждое событие, даже потерянное, снова «глушит» детектор на $\tau$. При очень большой загрузке такой детектор замолкает совсем.

У **непродлевающегося** типа после записанного события канал занят ровно $\tau$, а события в это время просто пропадают. Записанных событий $m$ в секунду, мёртвая доля времени $m\tau$, поэтому $m = n(1 - m\tau)$:

$$
n = \frac{m}{1 - m\tau},\qquad m = \frac{n}{1 + n\tau}.
$$

При малой поправке $m\tau \ll 1$ оба типа дают одно и то же — ту же формулу, что первое приближение выше.

  initial={0}
  steps={[
    { note: 'Поправка: $m\\tau = 5000\\cdot2\\cdot10^{-5} = 0.1$:', tex: 'n = \\frac{5000}{0.9} \\approx 5556\\ \\text{с}^{-1}' },

    { note: '**Ответ.** $n = 5556 \\pm 11$ с⁻¹; потеряно $1 - m/n = 10\\ \\%$ событий.' },
