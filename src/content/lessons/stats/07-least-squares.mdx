## Идея метода

Пусть измерены точки $(x_i, y_i)$ с погрешностями $\sigma_i$, и есть модель $y = f(x; a, b, c)$ с неизвестными параметрами. Насколько модель расходится с данными, покажет сумма квадратов отклонений, где каждое отклонение измерено в своих $\sigma$:

$$
S(a, b, c) = \sum_{i=1}^{N}\left(\frac{y_i - f(x_i; a, b, c)}{\sigma_i}\right)^2.
$$

Лучшие параметры — те, при которых $S$ минимальна. Условия минимума — нулевые частные производные:

$$
\frac{\partial S}{\partial a} = 0,\qquad \frac{\partial S}{\partial b} = 0,\qquad \frac{\partial S}{\partial c} = 0.
$$

Деление на $\sigma_i$ важно: точное измерение должно влиять на результат сильнее неточного. Если все $\sigma_i$ одинаковы, они сокращаются, и остаётся просто сумма квадратов.

## Взвешенное среднее

Простейшая модель — константа: $f = a$. Несколько измерений одной величины разными методами — какое у неё общее значение?

  steps={[
    { note: 'Функционал для константы:', tex: 'S(a) = \\sum_i \\frac{(a_i - a)^2}{\\sigma_i^2}' },
    { note: 'Условие минимума:', tex: '\\frac{dS}{da} = -2\\sum_i \\frac{a_i - a}{\\sigma_i^2} = 0 \\;\\Rightarrow\\; \\bar a = \\frac{\\sum a_i/\\sigma_i^2}{\\sum 1/\\sigma_i^2}' },
    { note: 'Это среднее с **весами** $w_i = 1/\\sigma_i^2$. Погрешность — по переносу: $\\partial\\bar a/\\partial a_i = w_i/\\sum w$, поэтому', tex: '\\sigma_{\\bar a}^2 = \\sum_i \\left(\\frac{w_i}{\\sum w}\\right)^2\\sigma_i^2 = \\frac{1}{\\sum w_i},\\qquad \\sigma_{\\bar a} = \\frac{1}{\\sqrt{\\sum 1/\\sigma_i^2}}' },
    { note: 'При равных $\\sigma_i = \\sigma$ получаются обычное среднее и знакомая погрешность $\\sigma/\\sqrt N$ из урока 1.' },

**Согласуются ли измерения?** Если погрешности честные, каждое слагаемое $S$ в среднем около единицы, и $S_{\min}$ близко к числу степеней свободы — числу точек минус числу параметров (сумма квадратов подчиняется распределению $\chi^2$, раздел 9 пособия). У трёх измерений с лекции $S_{\min} = 0.26 + 0.46 + 0.48 \approx 1.2$ при $3 - 1 = 2$ степенях свободы — всё согласовано. Если бы вышло 20, погрешности занижены или в одном измерении ошибка.

## Прямая через точки

Модель $y = kx + b$. Если погрешности точек одинаковы, $S(k, b) = \sum (y_i - kx_i - b)^2$.

<Steps
  client:visible
  title="Вывод: формулы прямой"
  initial={1}
  steps={[
    { note: 'Производная по $b$:', tex: '\\frac{\\partial S}{\\partial b} = -2\\sum (y_i - kx_i - b) = 0 \\;\\Rightarrow\\; b = \\bar y - k\\bar x' },
    { note: 'Прямая МНК проходит через «центр тяжести» точек $(\\bar x, \\bar y)$. Подставим $b$ и возьмём производную по $k$:', tex: '\\frac{\\partial S}{\\partial k} = -2\\sum x_i\\bigl((y_i - \\bar y) - k(x_i - \\bar x)\\bigr) = 0' },
    { note: 'Так как $\\sum \\bar x(\\ldots) = 0$, можно заменить $x_i$ на $x_i - \\bar x$:', tex: 'k = \\frac{\\sum (x_i - \\bar x)(y_i - \\bar y)}{\\sum (x_i - \\bar x)^2}' },
  ]}
/>

Подберите прямую сами: двигайте наклон и сдвиг, пока сумма квадратов не перестанет уменьшаться, — и сравните с решением МНК.
