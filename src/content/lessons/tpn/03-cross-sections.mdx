## Рассеяние и поглощение: классификация по балансу

Любое столкновение приводит либо к **рассеянию**, либо к **поглощению**. Делят их по балансу нейтронов: при рассеянии число нейтронов не меняется — меняются энергия и направление. При поглощении исходный нейтрон исчезает. Если в реакции рождаются новые нейтроны (деление, (n, 2n)), их учитывают **как источники** в уравнении баланса.

| Класс | Процесс | Схема | Что важно |
|---|---|---|---|
| Рассеяние | Потенциальное | волна рассеивается на потенциале ядра, не проникая внутрь | Идёт при любой энергии; зависит только от радиуса ядра; состояние ядра не меняется |
| | Упругое резонансное | ${}^{A}_{Z}B + n \to {}^{A+1}_{Z}B^* \to {}^{A}_{Z}B + n$ | Через составное ядро; энергия нейтрона в системе центра инерции не меняется |
| | Неупругое | $\to {}^{A}_{Z}B + n' + \gamma$ | Ядро остаётся возбуждённым, остаток уносят γ. Пороговое: нужна энергия выше первого уровня ядра |
| Поглощение | Радиационный захват | $\to {}^{A+1}_{Z}B + \gamma$ | Образуется новый изотоп |
| | Деление | $\to C + D + \nu n + \gamma$ | Новые нейтроны идут в источник |
| | (n, 2n), (n, 3n) | $\to {}^{A-1}_{Z}C + 2n + \gamma$ | Пороговые: выше энергии связи нейтрона (несколько МэВ) и двух энергий связи соответственно |
| | (n, p), (n, α) | ¹⁰B(n, α)⁷Li, ⁶Li(n, α)T | Обычно при высоких энергиях; исключения — ядра с аномально низкой энергией связи |

> **Ловушка.** Реакция (n, 2n) — это **поглощение**, хотя нейтронов на выходе два. Исходный нейтрон исчез, а два новых считаются рождёнными источником.

### Модель составного ядра

Почти все реакции, кроме потенциального рассеяния (до ~20 МэВ), идут в две стадии. Сначала ядро поглощает нейтрон, образуя составное ядро с энергией возбуждения $E^* = E_{\text{св}} + E$ — 5–7 МэВ у лёгких ядер, 7–9 МэВ у средних и тяжёлых. Затем через $10^{-17}$–$10^{-13}$ с составное ядро распадается, «забыв», как образовалось. Вероятность образования максимальна, когда $E^*$ попадает на уровень составного ядра. Отсюда **резонансы** в сечениях.

- **Лёгкие ядра** (¹²C): первый уровень лежит высоко — выше сотен кэВ, у углерода выше 1 МэВ. Ниже идёт только потенциальное рассеяние, сечение почти постоянно (≈ 4.7 б).
- **Тяжёлые ядра** (²³⁸U): уровни плотные, первый резонанс при 6.67 эВ. Дальше **область разрешённых резонансов** (до единиц кэВ, ширина уровня меньше расстояния между уровнями), затем **неразрешённых** (уровни перекрываются), затем плавная зависимость. Выше нескольких МэВ открывается (n, 2n), выше двух энергий связи — (n, 3n).

## Микроскопическое сечение

**Мысленный опыт.** На тонкую фольгу — толщина $X \ll \lambda$, площадь $S$, ядер в единице объёма $N$ — перпендикулярно падает коллимированный моноэнергетический пучок интенсивностью $I$ [нейтр./(см²·с)]. Скорость взаимодействий пропорциональна интенсивности и полному числу ядер:

$$
R_{\text{вз}} = \sigma \cdot I \cdot (N S X) \quad\Rightarrow\quad \sigma = \frac{R_{\text{вз}}}{I\,N\,S\,X}.
$$

**Смысл:** число взаимодействий в единицу времени на одно ядро мишени при единичной интенсивности пучка. Размерность — см², единица — **барн**: 1 б = 10⁻²⁴ см². Сечение характеризует вероятность реакции и зависит от ядра и энергии нейтрона.

**Зачем «тонкая» фольга?** Чтобы каждое ядро «видело» один и тот же пучок $I$, без ослабления внутри фольги. Точная доля провзаимодействовавших $1 - e^{-\Sigma X}$ совпадает с $\Sigma X$ только при $\Sigma X \ll 1$ — это вывод урока 4.

Сечения аддитивны:

$$
\sigma_t = \sigma_a + \sigma_s,\qquad \sigma_a = \sigma_c + \sigma_f + \sigma_{n,2n} + \dots,\qquad \sigma_s = \sigma_{el} + \sigma_{in}.
$$

## Макроскопическое сечение

$$
\Sigma_i = \sigma_i N\ \ [\text{см}^{-1}], \qquad \Sigma_i^{\text{смесь}} = \sum_k \sigma_i^k N_k, \qquad N = \frac{\rho N_A}{M}.
$$

$\Sigma$ — характеристика **среды** (состава и плотности) при данной энергии. Физический смысл — вероятность взаимодействия на единице пути; его выведем в уроке 4.

<SigmaCalculator client:visible />

> **Из конспекта: «$\Sigma_f = 0.1$ см⁻¹ — при каком спектре, при какой энергии?»** Значение $\Sigma$ без указания энергии или спектра, по которому усреднили, ничего не значит. Калькулятор выше считает в одной тепловой точке. В реальном реакторе сечения усредняют по спектру нейтронов — это тема урока 6.
